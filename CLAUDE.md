# mazda-cx5

Учебный проект: страничка Mazda CX-5 2020 (Machine Grey) для практики git.

## Главное правило
Пользователь учится git. **Git-команды выполняет сам** в терминале / VS Code.
Claude только пишет код фич и подсказывает, что делать дальше. Не делай `git add/commit/push/merge/rebase` и т.п. без прямой просьбы.
Читать состояние (`git status`, `git log`) — можно, чтобы проверить упражнение.

## Карта
- `index.html` — разметка
- `styles.css` — стили, цвета в `:root`
- `script.js` — появится в упражнениях
- `docs/EXERCISES.md` — план упражнений и прогресс

## Стек
Чистые HTML/CSS/JS, без сборки и зависимостей — чтобы ничего не отвлекало от git.
