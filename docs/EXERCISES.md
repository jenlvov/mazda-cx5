# Упражнения по git

**Роли:** git делаешь ты (терминал VS Code `` Ctrl+` `` или панель Source Control `Ctrl+Shift+G`).
Claude играет «коллегу»: пишет код фич, создаёт «чужие» изменения, проверяет результат через `git log`.

Отмечай `[x]` по мере прохождения — это тоже будет коммит.

---

## Уровень 1. Основа

- [X] **0. Настройка git** — имя, почта, ветка `main` по умолчанию, VS Code как редактор.
- [X] **1. Первый коммит** — `git init`, `.gitignore`, `status` → `add` → `commit`, `log`.
- [X] **2. GitHub** — создать пустой репозиторий, `remote add`, `push -u`.
- [X] **3. Цикл изменений** — Claude добавляет таблицу характеристик; смотришь `diff`, коммитишь, пушишь.
- [X] **4. Частичный коммит** — в одном файле две несвязанные правки; коммитишь их раздельно (`git add -p` или Stage Selected Ranges в VS Code).

## Уровень 2. Ветки и pull request

- [ ] **5. Ветка + PR** — ветка `feature/gallery`, 2–3 коммита, push, Pull Request на GitHub, merge, удаление ветки, `pull` локально.
- [ ] **6. Конфликт** — две ветки меняют одну строку (цену); merge, разрешение конфликта в Merge Editor VS Code.
- [ ] **7. Конфликт в PR** — `main` ушёл вперёд, PR не мержится; подтягиваешь `main` в ветку и решаешь конфликт.
- [ ] **8. Code review** — оставляешь комментарии к строкам в PR, правишь по ним, разные способы merge (merge commit / squash / rebase).

## Уровень 3. Исправление ошибок

- [ ] **9. amend** — поправить сообщение и забытый файл в последнем коммите.
- [ ] **10. restore / reset** — откат правок в рабочей папке, снятие с индекса, `reset --soft / --mixed / --hard`.
- [ ] **11. revert** — Claude «ломает» страницу коммитом, который уже запушен; отменяешь через `revert`.
- [ ] **12. reflog** — «теряешь» коммит через `reset --hard` и находишь его обратно.

## Уровень 4. Продвинутое

- [ ] **13. stash** — срочный фикс посреди незаконченной работы.
- [ ] **14. cherry-pick** — из экспериментальной ветки забрать в `main` только один полезный коммит.
- [ ] **15. rebase** — переписать ветку поверх свежего `main`, линейная история.
- [ ] **16. Интерактивный rebase** — склеить «wip»-коммиты (`squash`), переименовать, переставить.
- [ ] **17. Теги и релиз** — `v1.0.0`, Release на GitHub.
- [ ] **18. bisect** — найти коммит, сломавший страницу, среди 10 коммитов.
- [ ] **19. GitHub Pages** — опубликовать страничку из репозитория.

## Шпаргалка

| Что | Команда |
|---|---|
| Что изменилось | `git status`, `git diff`, `git diff --staged` |
| История | `git log --oneline --graph --all` |
| Ветки | `git switch -c имя`, `git switch имя`, `git branch -d имя` |
| Синхронизация | `git fetch`, `git pull`, `git push` |
| Отмена | `git restore файл`, `git restore --staged файл`, `git revert хэш` |
